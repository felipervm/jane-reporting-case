# Jane Reporting Case Study

Independent product + data case study by Felipe Mattos.

This project explores a narrow question in Jane's public reporting workflows: where recurring clinic-owner questions may still require repeated setup, exports, or external analysis — and how that opportunity should be validated before any product change is built.

## What this demonstrates
- product research
- data reasoning
- workflow analysis
- evidence-led problem framing
- changing direction when counter-evidence appears
- practical validation before roadmap decisions
